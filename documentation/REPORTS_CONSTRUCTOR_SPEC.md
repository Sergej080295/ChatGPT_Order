# Конструктор страниц / Отчёты — техническое задание

## Цель доработки
Реализовать универсальный конструктор страниц (отчётов/дашбордов) в Планировщике для свободного составления страниц из данных по заказам и их переделам. Система должна поддерживать создание пресетов, гибкую визуализацию (таблицы, графики, Ганты, KPI-плитки), управление доступом и персональные настройки отображения.

## Общая концепция
- В интерфейсе появляется раздел «Отчёты» как выпадающий список доступных пользователю пресетов. Раздел виден только при включённой настройке и наличии прав.
- Появляется раздел «Конструктор» для создания и редактирования шаблонов страниц. По умолчанию он пустой (или показывает список пресетов и кнопку создания). Пользователь сам конфигурирует структуру страницы и размещает элементы.
- Пресет страницы — сохранённая конфигурация (виджеты, их размеры, расположение и настройки данных).

## Основной функционал конструктора
- Свободное размещение элементов на странице (drag & drop) и изменение их размеров.
- Сохранение компоновки и дальнейшее редактирование пресетов.
- Возможность создавать несколько вариантов страниц под разные задачи.

## Типы элементов
### 1. Таблица
- Источники данных: по заказам (1 строка = 1 заказ) или по переделам (1 строка = 1 передел заказа).
- Настройки: выбор столбцов, сортировка по любому столбцу, фильтры, строка итогов (суммы, количество, агрегаты).
- Поддерживаемые данные: статусы и состояние заказа, наличие комментариев, готовность, наличие переделов, просрочка, суммы услуг и другие агрегаты.
- Поведение: двойной клик по наименованию заказа всегда открывает окно редактирования заказа.

### 2. Диаграмма Ганта
- Использование существующих Гантов по переделам или отдельных, созданных для конструктора.
- Возможность нескольких вариантов (например, отдельные Ганты для лазера, гибки и других переделов).
- Настройка отображаемых данных и фильтров.

### 3. Графики
- Различные варианты визуализации (линейные, столбчатые и т.п.).
- Выбор источника данных и параметров отображения.

### 4. Маршрут заказа
- Аналогично существующей странице переделов.
- Можно включать или отключать фильтры и отображаемые элементы.

### 5. Плитки (KPI)
- Отображение ключевых показателей: загрузка переделов (например, лазер), количество услуг в производстве, другие агрегированные метрики.
- Изменение размеров и положения плиток для сборки дашбордов.

### 6. Готовый дашборд
- Преднастроенный набор элементов (загрузка, выработка, ключевые производственные показатели).

## Фильтрация и данные
- Фильтры настраиваются индивидуально для каждого элемента и сохраняются в составе пресета.
- В первой итерации достаточно базовых операторов: равно / не равно, диапазон дат, выбор из списка, наличие / отсутствие.

## Пресеты страниц
- Поддерживается неограниченное количество пресетов.
- Атрибуты пресета: имя, описание (опционально), статус отображения в интерфейсе, настройки доступности по ролям.
- Пользователь в личных настройках выбирает, какие доступные ему пресеты показывать в разделе «Отчёты».

## Права доступа и роли
- Права: просмотр «Отчётов», доступ к «Конструктору», создание/редактирование/удаление пресетов, использование пресетов (просмотр).
- Отображение «Отчётов» и доступ к конструктору зависят от включённой настройки и наличия соответствующих прав.

## Поведение интерфейса
- Двойной клик по наименованию заказа всегда открывает окно редактирования заказа, вне зависимости от типа страницы или элемента.
- Изменения пресетов сохраняются и применяются при последующих открытиях.

## Архитектурные требования
- Рекомендуется разделить решение на конструктор данных (наборы данных, источники, фильтры) и конструктор страниц (визуальное размещение элементов).
