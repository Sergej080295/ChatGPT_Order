# PlanCore UI Notes

## Design tokens
- Базовые токены определены в `public/plan-core.css` в секции `:root` (светлая тема) и в классе `.theme-dark` для тёмной темы.
- Используемые переменные:
  - Цвета: `--pc-bg`, `--pc-surface`, `--pc-text`, `--pc-text-muted`, `--pc-border` и статусы `--pc-status-*`.
  - Акценты: `--pc-primary`, `--pc-danger`, `--pc-info`, `--pc-ok`.
  - Типографика: размеры заголовков (`--pc-h1-size` и т.д.), веса (`--pc-font-weight-*`), шрифт `--pc-font-sans`.
  - Отступы и радиусы: `--pc-spacing-*`, `--pc-radius-*`.
- Для новых компонентов достаточно подключить `plan-core.css` и переиспользовать классы `pc-*` (кнопки, бейджи, карточки).

## Темы
- Переключение светлой/тёмной темы реализовано в `public/plan-core.js` через сохранение настройки `plancore_theme` в `localStorage`.
- Для применения темы достаточно добавить атрибут `data-action="toggle-theme"` к кнопке и поставить `data-section` на `body` для подсветки активного раздела.
- Тёмная тема включает класс `theme-dark` на элементе `<body>`.

## Компоненты
- Заголовок и навигация используют класс `pc-header`; навигационные ссылки подсвечиваются автоматически по `body.dataset.section`.
- Базовые кнопки: `pc-btn` с модификаторами `pc-btn--primary`, `pc-btn--secondary`, `pc-btn--danger`, `pc-btn--ghost`. Для иконок — `pc-icon-btn`.
- Бейджи и статусы: `pc-badge` + атрибут `data-status` (`working`, `done`, `overdue`, `waiting`).
- Карточки и поверхности: класс `pc-surface` или `pc-card` уже содержит фон, тень и радиус из токенов.
- Тосты: контейнер `pc-toast-layer`, элементы `pc-toast` с `data-variant` (`info`, `success`, `warning`, `danger`).

## Расширение
1. Добавьте свои переменные в `plan-core.css`, сохраняя префикс `--pc-`.
2. Для компонентов создавайте утилитарные классы `pc-*` — они наследуют тему и типографику.
3. Избегайте жёстко заданных цветов: используйте `var(--pc-...)` или `color-mix` с существующими токенами.
