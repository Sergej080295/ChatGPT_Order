# Словарь терминов PlaneCore

- **Передел** — стадия производственного процесса, которую необходимо запланировать и выполнить по заказу.
- **Диаграмма Ганта** — визуальное представление загруженности переделов по календарю с указанием занятых и свободных часов.
- **Фактические даты** — реальные даты начала и окончания передела, зафиксированные после выполнения работ.
- **Плановые даты** — рассчитанные системой или вручную назначенные даты, по которым должно пройти выполнение передела.
- **Остаток часов** — количество свободных часов ресурса на выбранную дату после учета запланированных задач.
- **Не учтённые** — раздел, отображающий заказы со статусами, исключёнными из основной загрузки согласно настройкам видимости.
- **Сопоставление стадий** — настройка соответствия стадий из CRM внутренним переделам PlaneCore для корректного распределения заказов.
- **Отгрузка** — финальный передел (стадия `Отгружено/Ship`), после которого заказ считается завершённым.
