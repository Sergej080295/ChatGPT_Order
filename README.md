# Planner Server

Этот репозиторий содержит одностраничное приложение планировщика (`Planner_v2.html`) и Node.js‑сервер (`server.js`),
который сохраняет состояние планировщика в SQLite‑базу данных.

## Основные возможности сервера

- Отдаёт статическую версию планировщика и актуальный номер версии (`/api/version`).
- Принимает актуальное состояние интерфейса и раскладывает его по SQL‑таблицам (`/api/state`, метод `POST`).
- Возвращает сохранённое состояние, историю сохранений и список задач из SQL (`/api/state`, `/api/history`, `/api/tasks`).
- Хранит данные в файле `planner.db` (путь можно переопределить переменной окружения `DB_PATH`).

## Быстрый старт

1. Установите зависимости: `npm install`.
2. Запустите сервер: `npm start`.
3. Откройте в браузере `http://localhost:3000`.

Подробнее о запуске см. в разделе «Развёртывание» ниже.

## Развёртывание

1. Установите [Node.js 18+](https://nodejs.org/) и npm.
2. Склонируйте репозиторий и перейдите в директорию проекта.
3. Установите зависимости сервера: `npm install`.
4. При необходимости задайте переменные окружения:
   - `PORT` — порт HTTP (по умолчанию `3000`).
   - `DB_PATH` — путь к файлу SQLite (по умолчанию `planner.db` в корне проекта).
   - `STATIC_ROOT` — директория с `Planner_v2.html`, если она отличается от корня проекта.
5. Запустите сервер: `npm start`.
6. Откройте `http://localhost:PORT` в браузере и проверьте индикатор в правом верхнем углу интерфейса.

### Ручное тестирование API

- Текущее состояние: `GET http://localhost:3000/api/state`.
- Сохранение состояния: `POST http://localhost:3000/api/state` с телом `{ "state": { ... }, "version": "v2025.09.22-rc2" }`.
- История сохранений: `GET http://localhost:3000/api/history`.
- Задачи из SQL: `GET http://localhost:3000/api/tasks?stage=bend`.
