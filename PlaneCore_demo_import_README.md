# Демо-база PlaneCore (v5.54)

Файл для импорта: `PlaneCore_demo_import_v5.54.json`.

## Что внутри
- 1 демо-доска: **«Демо-доска PlaneCore (презентация)»**.
- 36 заказов в разных статусах канбана (распределение намеренно неравномерное; 2 колонки пустые для демонстрации фильтров и автоскрытия).
- Переделы по текущей логике CRM, включая **«Поставка ДС»**.
- Комментарии к заказам, даты входа в статус, суммы услуг, журнал изменений.
- Заполнены настройки для демонстрации подсветки колонок по простоям (7+ дней), при этом просроченные заказы составляют менее 30% от общего количества.

## Как подгрузить в CRM
1. Откройте CRM в браузере и войдите в систему.
2. В верхней панели нажмите кнопку **«Импорт JSON»** (иконка стрелки вниз).
3. Выберите файл `PlaneCore_demo_import_v5.54.json`.
4. Дождитесь сообщения **«Импорт завершён»**.

## Важно
- Импорт заменяет текущее состояние CRM в браузере на данные из файла (с объединением части настроек).
- Для повторяемой демонстрации лучше импортировать файл в «чистом» профиле браузера или после экспорта ваших рабочих данных.
